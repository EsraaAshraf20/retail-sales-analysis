Explore sales performance, category revenue, and monthly trends through interactive Plotly charts.

This project analyzes retail sales data to understand sales performance, product categories, monthly trends, and customer demographics.

Objectives

* Analyze total sales and average transaction value.
* Compare revenue across product categories.
* Explore monthly sales trends.
* Understand customer demographics and purchasing behavior.
* Build an interactive dashboard using Plotly.

Tools & Technologies

* Python
* Pandas
* Plotly
* Google Colab

Dataset

Retail Sales Dataset from Kaggle:

https://www.kaggle.com/datasets/mohammadtalib786/retail-sales-dataset

Key Findings

* Total sales reached 456,000 across 1,000 transactions.
* Electronics generated the highest category revenue at 156,905.
* May 2023 was the strongest complete month, with sales of 53,150.
* Quantity and transaction value showed a moderate positive correlation of 0.374.

Limitations

* Product cost data is unavailable, so profit cannot be calculated.
* January 2024 contains data for only one day and is excluded from the monthly comparison.

How to Run

1. Open the notebook in Google Colab.
2. Upload the dataset CSV file.
3. Run the notebook cells in order.
4. Explore the analysis and interactive dashboard.
